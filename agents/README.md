# Agent Team Directory

This directory stores the personas, operational specifications, and system prompts for each specialized agent in the College Management System project.

## Agent Roster

1. **[`backend-architect.md`](./backend-architect.md)**: Spring Boot backend engineer, JPA entities, REST APIs, Security, DTOs, business services.
2. **[`database-architect.md`](./database-architect.md)**: Database architect, MySQL 8, Flyway migration versioning, indexing, and referential integrity.
3. **[`react-engineer.md`](./react-engineer.md)**: React frontend developer, Vite, TypeScript, TanStack Query, Tailwind/CSS, component architecture.
4. **[`angular-engineer.md`](./angular-engineer.md)**: Angular frontend developer, Signals, RxJS, Reactive Forms, Guards, Interceptors.
5. **[`devops-engineer.md`](./devops-engineer.md)**: Docker multi-stage builds, docker-compose orchestration, GitHub Actions CI/CD.
6. **[`qa-engineer.md`](./qa-engineer.md)**: Unit, integration, and E2E testing strategies across backend and both frontends.
